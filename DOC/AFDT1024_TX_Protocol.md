# Ka 波段 1024 单元发射子阵（无变频）控制接口协议（UART）

## 版本信息
- 协议代号：AFDT1024 Control Frame  
- 版本：V1  
- 日期：2025-12-23  

---

## 1. 串口参数

| 参数 | 值 |
|---|---|
| 波特率 | 460800 |
| 数据位 | 8 |
| 校验 | None |
| 停止位 | 1 |
| 流控 | None |

---

## 2. 通用帧格式

```
[0x50][0x53][0x41][ID][LEN][DATA...][CHECKSUM]
```

| 字段 | 长度 | 说明 |
|---|---|---|
| 帧头 | 3 Byte | 固定 0x50 0x53 0x41 |
| ID | 1 Byte | 子阵 ID |
| LEN | 1 Byte | DATA 长度 |
| DATA | N Byte | 数据区（最低字节为 ADDR） |
| CHECKSUM | 1 Byte | 前面所有字节求和取低 8 位 |

---

## 3. ID 规则

| ID | 行为 |
|---|---|
| 0x00 | 所有子阵接收，不返回 |
| ID | 所有子阵接收，对应 ID 返回 |
| ID + 0x80 | 仅对应 ID 接收并返回 |

---

## 4. 指令定义

### 4.1 TX 波束设置（ADDR = 0x50）

- 数据长度：5 Byte  
- 指令间隔建议 ≥ 2 ms  

```
[FREQ][BeamV_H][BeamV_L][BeamH_H][BeamH_L][0x50]
```

- FREQ：0~70  
- 实际频率：27500 + 50 × FREQ (MHz)

角度补码：
- 0~2047 → 0°~+180°
- 2048~4095 → -180°~0°

---

### 4.2 TX 阵列使能（ADDR = 0x51）

- 数据长度：5 Byte  

```
[TX_EN_ROW_H][TX_EN_ROW_L][0xFF][0xFF][0x51]
```

- 0xFFFF：发射阵列开启  
- 0x0000：发射阵列关闭  

---

### 4.3 TX 极化设置（ADDR = 0x53）

- 数据长度：5 Byte  

```
[POL][0x00][0x00][0x00][0x53]
```

- POL = 0：LHCP  
- POL = 1：RHCP  

---

### 4.4 TX 推动 PA 使能（ADDR = 0x56）

- 数据长度：5 Byte  

```
[PA_EN][0x00][0x00][0x00][0x56]
```

- PA_EN = 0：PA 关闭  
- PA_EN = 1：PA 使能  
- 上电默认：0  

---

### 4.5 TX 整板相位偏移校准（ADDR = 0x57）

- 数据长度：5 Byte  

```
[PS_Align][0x00][0x00][0x00][0x57]
```

- PS_Align：0~63  
- 步进：5.625°  
- 上电默认：0  

---

### 4.6 ID 更新（ADDR = 0x20）

- 数据长度：3 Byte  
- 使用公共 ID（0x00）  

```
[ID_new][0x00][0x20]
```

- 默认出厂 ID：0x01  
- 修改后需重新上电  

---

### 4.7 状态查询（ADDR = 0x5C）

- 数据长度：1 Byte  

#### 查询命令
```
[0x5C]
```

#### 返回数据（LEN = 6）
```
[Rev][STATE][SysVcc][SysTemp][ATT_Tc][MCU_VER]
```

- STATE.B0：PA_EN 状态  
- SysVcc：value × 0.1 V  
- SysTemp：value − 80 (℃)  

---

## 5. 波束计算模型

```
ux = 180 × (f / f0) × sin(θ) × cos(φ)
uy = 180 × (f / f0) × sin(θ) × sin(φ)
```

- Tx_f0 = 30000 MHz  
- BeamH = ux（补码）  
- BeamV = uy（补码）  

---

## 6. 子阵拼阵 ID 规则

```
0x01   0x11
0x02   0x12
...
```

- 左列：0x01 ~ 0x0N  
- 右列：0x11 ~ 0x1N
