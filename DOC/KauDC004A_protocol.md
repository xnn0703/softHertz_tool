
# KaUDC004A 控制协议文档

---

# 1. 控制接口

## 1.1 接插件定义

**模块供电与控制接插件型号：**

```
J30J-9ZKWP
```

---

## 1.2 通信接口标准

* 通信方式：RS232
* 协议类型：UART 异步串口
* 波特率：115200 bps
* 数据位：8 bit
* 起始位：1 bit
* 停止位：1 bit
* 校验位：无
* 数据格式：8N1

---

# 2. 帧格式定义

## 2.1 CRC 计算方式

* 多项式：

```
G(X) = X16 + X12 + X5 + 1
```

* Poly 值：`0x1021`
* 初始值：`0xFFFF`
* CRC 校验范围：

```
字节0 ~ 字节9（帧头 + 载荷）
```

* 传输方式：**大端字节序**

# 3. 命令帧定义

---

## 3.1 复位命令

### 命令码

```
0x0A
```

### 命令格式

| Byte4 | Byte5 | Byte6 | Byte7 | Byte8 | Byte9 |
| ----- | ----- | ----- | ----- | ----- | ----- |
| 0x0A  | 0x00  | 0x00  | 0x00  | 0x00  | 0x00  |

### 回复格式

| Byte4 | Byte5 | Byte6 | Byte7 | Byte8 | Byte9 |
| ----- | ----- | ----- | ----- | ----- | ----- |
| 0x0A  | 0xFF  | 0x00  | 0x00  | 0x00  | 0x00  |

### 功能说明

复位整个变频分机。

复位后默认参数：

* 接收：

  * 频率：17.25 GHz（18.2–19.2）
  * Rx_ATT = 0
  * 增益 = 45 dB

* 发射：

  * 频率：28.05 GHz（29.00–30.0）
  * Tx_ATT = 0
  * 增益 = 26 dB

## 3.3 温度查询

### 命令码

```
0x0C
```

### 命令格式

| Byte4 | Byte5 | Byte6 | Byte7 | Byte8 | Byte9 |
| ----- | ----- | ----- | ----- | ----- | ----- |
| 0x0C  | 0x00  | 0x00  | 0x00  | 0x00  | 0x00  |

### 回复格式

| Byte4 | Byte5 | Byte6 | Byte7 | Byte8 | Byte9 |
| ----- | ----- | ----- | ----- | ----- | ----- |
| 0x0C  | Temp  | 0x00  | 0x00  | 0x00  | 0x00  |

### 温度编码规则

* `0x80 = 0℃`
* 小于 `0x80` → 负温度
* 大于 `0x80` → 正温度
* 分辨率：1 bit = 1℃
