  不增加不可判定的双编码自动兼容。
- Driver 的 TX/RX 摘要均使用“档位 + 有效子阵规模”，原始十六进制帧仍完整保留。

  TX/RX 当前档位更新下拉框、网格和摘要，不再解释结果、电源或应用状态。

  当前档位，但仍返回当前两字节快照。
