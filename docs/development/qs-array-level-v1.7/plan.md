# AFD01_QS 阵列档位上位机适配计划

## 目标

- AFD01_QS 对外协议版本统一标记为 V1.7，与交付客户的受控协议文档一致。
- 将 QS 上位机的 `0x0B/0xA1` 公开语义从内部尺寸 `4～8` 改为客户档位 `1～5`。
- 客户界面展示档位及有效子阵规模，不展示芯片布局或内部掩码。
- 将 `0xA1 ARRAY_STATUS` 载荷精简为 2 字节 `tx_level, rx_level`，只回读当前 TX/RX 档位。
- 保持串口帧结构、单请求约束、3 秒超时、A0 100Hz 处理和全局报文监视器不变。

## 实现

- protocol 使用显式档位 profile：`1→8×8`、`2→10×10`、`3→12×12`、`4→14×14`、`5→16×16`。
- 0x0B 构帧只接受档位 `1～5/None`；A1 仅解码 2 字节
  `tx_level/rx_level`，并派生客户子阵规模。
- Driver、模拟器、日志摘要、Panel 状态统一使用 level 命名。
- 下拉框显示“档位N（M×M子阵）”，默认档位5。
- TX/RX 可视化改为 16×16 子阵网格，按显式档位 profile 展示 64/100/144/196/256 个有效子阵。
- Panel 收到 A1 后把两个回读档位作为当前确认状态；不再解析或展示结果位、电源状态、
  回显确认状态。设置无应答仍按原有 3 秒超时处理。
- 原始十六进制日志和通用监视器结构不变。

## 非目标

- 不自动兼容旧 `4～8` 线编码。
- 不兼容旧的 5 字节 A1；其载荷长度必须精确为 2。
- 不修改 AFDTR 工作区和其他设备协议。
- 不以模拟器测试替代真实设备或 Windows EXE 验收。

## 验证

- 更新协议、Driver、模拟器、网格和 Panel 测试，覆盖 2 字节 A1、旧 5 字节拒绝、
  档位确认和超时。
- 运行完整 `pytest`、`compileall` 和 Qt offscreen 冒烟。
- 运行 30 秒 QS 模拟器链路，确认 A0 频率和报文落盘不回退。
