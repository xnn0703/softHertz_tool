# AFD01 阵列波束扫描

状态：用户已确认，软件实现与验证完成；实板验收待执行。

## 最小范围

在独立 AFD01 Tab 增加扫描区，参考 KA_RF_UNIT 的交互，不修改其业务。
扫描由上位机推进，复用 Debug RF_BEAM（op 7）和现有手动模式/能力门禁；固件和 wire schema 不变。
目标：TX、RX、TX+RX。TX+RX 每点按 TX→RX 串行发送，分别确认发送结果，不声明硬件同步。
使用所选阵列当前已查询到的有效频率；需要改频时先用现有频率控件设置。扫描期间禁用其他写操作。

## 参数与顺序

θ 离轴角 -90..90°、φ 方位角 -360..360°；两轴分别设置起点、终点、正步长（最小0.1°），支持递增/递减。
一轴起终点相等即单轴扫描。θ 外层、φ 内层栅格扫描；终点统一包含，步长不能整除时末点使用终点。
使用整数0.1°单位生成点位，按索引计算，避免浮点累加漂移；点位按需生成。
默认 θ=0..30°/5°，φ=0..90°/10°，每点停留200ms，范围50..60000ms，默认TX、单次扫描。
停留从本点所有目标发送结果确认成功后计时，下一点再开始；这不是精确的点到点周期承诺。

## 控制与反馈

开始、暂停/继续、停止；显示完成点数/总点数、当前θ/φ、目标、等待结果或停留状态；状态标签换行。
沿用一次一条控制在途，只有owner发送成功才能推进。Driver增加携带请求id/操作/结果的完成信号，不解析人类日志文本。
扫描有控制在途时按100ms节拍查询结果，其他时间仍1Hz；查询保持一条在途，超时后才重新查询，避免不断淘汰稍迟响应。
暂停在已发送请求结算后停住；尚未发送的另一目标留待继续。继续时，已完成点重新停留完整间隔。停止立即取消后续点位/目标，已发送请求仍可能执行。
停止不归零、不关闭PA/阵列、不改变模式，保持最后设备输出。
超时、执行失败和状态失效保留当前点，按下述 2026-09-15 规则等待恢复并重试；退出手动、关闭页面或切换 Tab 终止扫描。
不增加循环扫描、设备端扫描任务、功率采集、自动寻峰或测量报告。
