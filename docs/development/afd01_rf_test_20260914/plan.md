# AFD01 Debug 网口射频测试计划
状态：2026-09-14 已按确认范围完成软件实现与验证；Windows/实板验收待执行。

新增独立 AFD01 顶层 Tab，与 KA_RF_UNIT 并列，Panel/Driver/协议独立。首版 AFD01C 实板验收，AFD01 构建兼容。
复用 UDP 4004 与 Debug extension、track 手动模式、transceiver/antenna 单槽和硬件 owner；不新增固件线程/队列/测试接管状态。
控制：变频 TX/RX LO/RF、衰减、IF、参考频率；阵列 TX/RX 开关、PA、频率/角度、极化、模式、衰减、大小。
Debug 专属协议/API/状态用 NDEBUG 裁剪；Release/旧固件未声明能力则 UI 禁用。
仅手动模式允许写，断网/关闭保持设置，恢复自动由 track md 0 明确执行。重新上线保留原发射请求重放行为。
UDP Driver 单条控制在途、超时不重发、1 Hz 查询；隐藏关闭 socket，返回重新连接查询，不重放设置。
不包含 OTA、持久化、扫描、任意行列掩码、多客户端管理或通用传输框架。

## Debug 离轴范围调整

用户确认测试离轴角允许 −90°～90°。手动波束、扫描、上位机协议与固件 Debug 命令入口同步调整，超出范围拒绝；Release 命令限幅和 Tracking 阵面能力不变。需使用更新后的 Debug 固件验证大于 70° 的请求，未执行固件下载。

## 连接默认行为与界面精简

用户确认默认地址 192.168.1.12；每次连接获得首次有效能力/状态后，非手动时自动请求一次手动模式。已有手动模式直接使用，自动请求失败不重试，仍可使用手动按钮；设备确认手动后才开放测试写操作。此规则替代原连接后仅查询的模式规则，射频设置和扫描仍不重放。

删除状态表最近请求行、页内报文及其页签；AFD01 隐藏公共报文监视器，其他工作区保留。Workspace 用单个静态可见性属性告知主窗口，不引入设备特判；原报文日志通路保留。界面为上方连接、左侧变频/扫描、右侧阵列/操作反馈、下方八行状态表。
