# AFDT1024 / AFDR1024 校准结果查询计划

状态：用户已确认先完成 RX，TX 待源码确认；2026-09-10。

## 目标与范围

在 AFDR1024 现有“查询全部状态”中增加校准结果查询，按子阵 ID 展示结果。只修改上位机，不修改阵列固件，不调整客户流量模拟的两项查询组合或发送时序。

## 协议依据

当前现场源码：`3-project_dev/6-Antenna_Array/1-AFDR1024/Firmware/Src/main.c` 的 `UART2_ReturnAlignData`（696 行起），以及 `module_port/antenna_protocol.h`、`module_port/app_measure.h`、`Inc/main.h`。这是当前 RX 源码依据，尚无 TX 源码证据；TX 是否使用同一指令及载荷等待设备方确认，不从其它命令推算。

RX 请求：`50 53 41 ID 01 9E CS`；ID=1 示例为 `50 53 41 01 01 9E 84`。回复总长 17 字节，LEN=11，包括 10 字节数据及命令 0x9E；末字节为此前所有字节累加的低 8 位。

| 数据偏移 | 字段 | 显示方式 |
| --- | --- | --- |
| 0 | LINK_ID | 校准记录 ID |
| 1 | TempOffset + 80 | 减 80 后的温度偏移 |
| 2 | InitATT | 初始衰减码 |
| 3 | ZcalEn | 原始标志值 |
| 4～7 | OFST_VL、OFST_HL、OFST_VR、OFST_HR | 四项校准原始码 |
| 8～9 | ATT_L、ATT_R | 左右衰减原始码 |

各字段均为单字节，无多字节端序转换。未核实的物理量比例不换算为 dB 或角度。外层回复 ID 用于现有设备行归属，LINK_ID 独立展示，避免相互覆盖。

## 设计

1. protocol 增加命令、独立构帧和严格 10 字节载荷解析；复用现有帧校验与流式拆帧。
2. Driver 的普通状态查询序列在原有两项后追加校准查询，保留现有 ID/+0x80 和调度机制；流量模拟使用的双查询构帧接口保持兼容。
3. 收到校准回复后通过正式状态模型合并，保留电压、温度、波束等其它字段。原始 TX/RX 继续进入 FrameRecord。
4. 状态区域增加可折叠“校准结果”表，每个子阵一行，字段未收到时显示 N/A；使用同一“查询全部状态”按钮。
5. 模拟器复用正式协议提供确定性回复；补充协议、拆粘包、Driver/UI 路径及模拟器测试。
6. 更新 README、协议说明与开发记录，对照验收表复核。
