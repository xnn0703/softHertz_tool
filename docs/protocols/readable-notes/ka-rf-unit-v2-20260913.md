# KA_RF_UNIT 客户协议 V2 同步说明

本说明是上位机实现摘要，不把旧 V1 原件改称 V2。
依据设备工作区 `3-satlite_comm_terminal/code/target/ka_rf_unit/doc/customer_protocol.md`
（App 0.3.0）及同工作树的 `rf_unit_protocol.h/.c`、`control.c`、`ymodem.c`。
源文档 SHA-256：`39276b14f5eaec0466fdcbe22105017efcbea987ee61380893c7519d4cf10116`。
该依据包含设备侧未提交修改；后续发布须再次核对设备合同，不能仅凭固件 HEAD 推断线值版本。

## 外层帧与兼容性

`50 53 41 02 type N payload CRC16_BE`，总长 N+8、最大 256 字节。
CRC16/CCITT-FALSE poly=0x1021、init=0xFFFF、非反射，覆盖帧头至 payload 末。
多字节整数字段大端；V1 无协商或降级。旧版本已知有效请求由设备回 V2 BAD_VERSION。
0x22 未定义，0x30 不再上报，0x20 带旧两字节频率载荷返回 BAD_LENGTH。
UART4 客户口 RS485 460800 8N1；同一时刻一个请求在途，响应或 2 秒超时后才发下一条。
MCU PD0/PD1 经板上收发器连接 A/B；PC3 DE 由设备控制，不把 MCU UART 引脚当总线。

## 0x20 / 0xA0 状态查询

请求空载荷，成功结果 46 字节、完整帧 54 字节，失败仅一个非零 result。

| payload 偏移 | 字段 |
|---|---|
| 0 | result u8 |
| 1 | uptime_ms u32 |
| 5 | conv_lock_mask u16（bit0 REF、bit1 RX LO、bit2 TX LO） |
| 7/8/9 | PA、TX、RX 最近发送使能 u8 |
| 10/12/14 | fw_major/minor/revision，各 u16 |
| 16/18/20/22 | RX RF/LO、TX RF/LO，各 u16 MHz |
| 24/26/28 | RX/TX 变频衰减 u16 ×0.1 dB、外参 u16 MHz |
| 30/32/34 | 变频/TX阵面/RX阵面温度 i16 ×0.1 ℃（补码） |
| 36/38/40/42 | TX H/V、RX H/V 波束码 u16 |
| 44/45 | RX/TX 极化 u8 |

快照不触发硬件回读，没有新增 freshness 字段；缓存为零可能表示尚未取得数据。
内部 C5/C7 负载 snapshot_version 仍为 1，与外层 V2 区分。
0x10 固定分段 LO 与 0x16 自由频率、0x11 临时变频衰减与 0x48 保存并应用、
0x46 阵面衰减保留各自语义，不以 OK/发送缓存替代物理 RF 验收。

## 自动安装 OTA

0x21/A1 BEGIN、0x23/A3 ABORT、0x24/A4 STATUS，三个请求均空载荷。
BEGIN 授权完整 YMODEM 会话结束后自动校验、持久化安装请求并复位，无 COMMIT 或 READY。

A4 成功基础载荷：result:u8、phase:u8、major/minor/revision:u16×3、boot_state:u8、
update_requested:u8、candidate_present:u8、last_result:u8，共 12 字节。
有候选时从偏移 12 追加 size:u32、crc32:u32、name_len:u8、ASCII 名称，共 21+N（最大 84）字节。
失败仅一个 result。phase 为 0 IDLE / 1 RECEIVING / 2 VERIFYING / 3 COMMITTING；
boot_state 为 0 PENDING / 1 STABLE / 2 GRACEFUL_REBOOT。
last_result 为本次运行最近自动复验/提交失败（05/09/0A/0B），00 表示无失败记录，不表示安装成功。
名称展示字段为 filename，不能覆盖通用 result 的 name。

上传文件必须为本 target 的版本化 App BIN basename，1..63 字节 ASCII，无路径/空白；
`ka_rf_unit_app_X.Y.Z_release.bin` 或 `beta.bin`，有效数据 1..786432 字节。
这些检查不构成固件签名或身份认证。

握手按设备当前 ymodem.c：等 C → block0 → ACK+C → 数据停等 ACK → EOT → NAK → EOT → ACK+C → 空 block0 → ACK。
支持 SOH128/STX1024、块号回绕；CRC16/XMODEM init=0（区别于外帧 init=FFFF）。
第一包擦除响应等 10 秒，数据响应等 2 秒，每包最多重试 10 次；无进展 10 秒、原始总时长 120 秒。
重复/错误包不无限刷新进展；末尾空包一旦完整接受即可能自动安装，末 ACK 丢失不撤销授权。

BEGIN 响应丢失不发送原始文件，等 10 秒窗口后恢复；原始取消用 CAN，普通模式才发 ABORT。
末 ACK 丢失停止原始重试，静默至少 200 ms 再查询。恢复查询约 1 秒间隔、2 秒单次超时、
180 秒总期限，容纳设备约 90 秒健康观察；BUSY、暂时无响应、旧版本或 PENDING 不立即判失败。
目标版本且 STABLE 才报告目标版本健康；同版本重装、恢复期限届满显示“结果未确认”。
真实 Flash/Boot、RS485 时序、断电恢复及 RF 输出保持仍需实板验证。
