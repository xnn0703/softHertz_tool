## 2. 通用帧格式

```
[0x50][0x53][0x41][ID][LEN][DATA...][CHECKSUM]
```

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 帧头 | 3 Byte | 固定 `0x50 0x53 0x41` |
| ID | 1 Byte | 子阵 ID |
| LEN | 1 Byte | DATA 字节数（含末尾 ADDR） |
| DATA | N Byte | 数据区（最低字节为 ADDR/指令号） |
| CHECKSUM | 1 Byte | 除 CHECKSUM 外所有字节求和取低 8 位 |

## 3. ID 规则

| ID | 行为 |
| --- | --- |
| 0x00 | 所有子阵接收，不返回 |
| ID | 所有子阵接收，对应 ID 返回 |
| ID + 0x80 | 仅对应 ID 接收并返回 |

## 4. 指令列表

> 收到 4.1～4.4 配置指令后，设备按 ID 规则**原封不动返回**该帧。
> KuR512B **没有** 0x93 极化独立指令；极化随 0x90 波束命令下发。
> KuR512B **没有** 0x9F 波束参数查询；只有 0x9C 状态查询。

### 4.1 RX 波束设置（ADDR = 0x90）

- 数据长度：5 Byte（不含帧头/ID/LEN/CHECKSUM）  
- 指令间隔建议 ≥ 2 ms  

数据区按字节（大端）：

```
[FREQ] [POL] [BeamV[11:4]] [BeamV[3:0]<<4 | BeamH[11:8]] [BeamH[7:0]] [0x90]
```

| 字段 | 位宽 | 说明 |
| --- | --- | --- |
| FREQ | 8 | 频段号 0..41，实际频率 = 10700 + 50×FREQ (MHz)，范围 10700..12750 |
| POL | 8 | 0..180 = 线极化角度（°）；254 = LHCP；255 = RHCP |
| BeamV | 12 | 12 bit 补码波控值，0..2047 → 0..+180°；2048..4095 → −180°..0° |
| BeamH | 12 | 同 BeamV |

### 4.2 RX 阵列使能（ADDR = 0x91）

- 数据长度：4 Byte  

```
[reserved(4)] [RX_EN_ROW(16)] [0xFFF(12)] [0x91]
```

- `RX_EN_ROW`：16 bit，按 D27..D12 位布局；`0xFFFF` = 全开（接收阵列打开），`0x0000` = 全关
- 低 12 bit 固定为 `0xFFF`
- 正文里"11 bit"与位布局 16 bit 不一致；以位布局（D27..D12）为准
- **与 AFDR1024 的差异**：AFDR1024 是 16 bit en_row + 0xFFFF；KuR512B 是 16 bit en_row + 0xFFF；低位填充宽度不同，不得共用构帧函数

### 4.3 RX 整板相位偏移校准（ADDR = 0x97）

- 数据长度：4 Byte  

```
[reserved(26)] [PS_Align(6)] [0x97]
```

- `PS_Align`：0..63，步进 5.625°；上电默认 0；该指令不具备保存功能

### 4.4 ID 更新（ADDR = 0x20）

- 数据长度：2 Byte，使用公共 ID（0x00）发送  

```
[reserved(8)] [ID_new(8)] [0x20]
```

- 默认出厂 ID：0x01；修改后需重新上下电验证

### 4.5 状态查询（ADDR = 0x9C）

- 查询命令数据长度：1 Byte（仅含 ADDR 0x9C），**指令间隔建议 ≥ 3 ms**  

```
[0x9C]
```

响应（LEN = 4，4 字节载荷，无尾部 ADDR；前 9 byte 求和校验）：

```
[Rev] [SysVcc] [SysTemp] [MCU_VER]
```

| 字段 | 说明 |
| --- | --- |
| Rev | 默认为 0；无业务含义 |
| SysVcc | 实际电压 = 值 × 0.1 V |
| SysTemp | 实际温度 = 值 − 80（℃） |
| MCU_VER | 系统版本号 |

> 注：本格式与 AFDR1024 V2.1（5 字节载荷含尾部 `0x9C`）不同，**不得共用**响应解析。设备实测报文 `50 53 41 01 04 0A 72 66 05 D0` 与本节表格一致。

## 5. 波束计算模型

```
Ux = 180 × (f / f0) × sin(θ) × cos(φ)        # θ 离轴角, φ 方位角, 单位度
Uy = 180 × (f / f0) × sin(θ) × sin(φ)
BeamH = AngleToCode_12bit(Ux)
BeamV = AngleToCode_12bit(Uy)

AngleToCode_12bit(ang):
    if ang >= 0:  code = round(ang × 2048 / 180)
    else:         code = round(ang × 2048 / 180 + 4096)
    return code mod 4096
```

- Rx_f0 = **12500 MHz**（与 AFDR1024 的 20270 MHz 不同，必须使用本协议的 f0）

### 计算结果示例（受控原件 P173~P182 复述）

| Freq(MHz) | θ(°) | φ(°) | BeamV (dec) | BeamH (dec) |
| --- | --- | --- | --- | --- |
| 11700 | 0 | 0 | 0 | 0 |
| 11700 | 30 | 0 | 0 | 958 |
| 11700 | 30 | 45 | 678 | 678 |
| 11700 | 30 | 90 | 958 | 0 |
| 12500 | 30 | 45 | 724 | 724 |

## 6. 子阵拼阵 ID 规则

```
0x01   0x11
0x02   0x12
...
```

- 左列：0x01..0x0N；右列：0x11..0x1N（最大 N=15）
- V3.1 起阵列坐标：X 轴为 Phi=0，Y 轴为 Phi=90

## 7. 与 AFDR1024 的差异（实现要点）

| 项 | AFDR1024 | KuR512B |
| --- | --- | --- |
| 频段 | 17700..21200 MHz | 10700..12750 MHz |
| f0 | 20270 MHz | 12500 MHz |
| 阵列使能（0x91） | 16 bit en_row + 0xFFFF | 12 bit en_row + 0xFFF |
| 极化（0x93） | 独立指令 | **无**，随 0x90 下发 |
| 波束参数查询（0x9F） | 16 字节 | **无** |
| 状态查询（0x9C） | Rev/SysVcc/SysTemp/ATT_Tc/MCU_VER（5 字节） | Rev/SysVcc/SysTemp/MCU_VER（4 字节，无 ATT_Tc、无尾部 ADDR） |

> KuR512B 必须复用独立 `devices/kur512/` 模块；不能直接复用 AFDR1024 的 `protocol.py`，否则会错误地按 16 bit en_row 与 5 字节状态响应处理。
