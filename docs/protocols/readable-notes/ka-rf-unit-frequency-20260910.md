# KA_RF_UNIT 频点命令补充（2026-09-10）

来源：客户提供的两张截图及确认，不覆盖既有 DOCX 原件。帧头、V1、大端、CRC 和串口规则不变。

两条命令载荷均为 10B：RX RF:u16、RX LO:u16、TX RF:u16、TX LO:u16（MHz），RX 极化:u8、TX 极化:u8（0/1）。

| 命令 / 应答 | 规则 |
|---|---|
| 0x10 / 0x90 | RF 与 LO 必须按下表匹配，0 不再表示 AUTO；不匹配返回 03 |
| 0x16 / 0x96 | 自由配置，LO=0 为 AUTO；手动 RX LO 为 16750–19250 偶数，TX LO 为 26550–29050 偶数 |

| TX RF MHz | TX LO MHz | RX RF MHz | RX LO MHz |
|---|---|---|---|
| [27500,28350) | 26550 | [17700,18200) | 16750 |
| [28350,29000) | 27400 | [18200,19200) | 17250 |
| [29000,30000) | 28050 | [19200,20200) | 18250 |
| [30000,31000] | 29050 | [20200,21200] | 19250 |

0x16 AUTO 使用同表；RF 范围仍受限。两条命令长度错误返回 02，参数越界返回 03；
错误请求不改变频点或极化。应答载荷为 1B result，00 只表示请求已接受，不代表 RF 已应用。
内部 0x44 角度使用最近接受的 0x10 或 0x16 RF；改频后需重发角度。

上位机默认“0x10 固定本振”，自动填入匹配的明确 LO；切到“0x16 自由配置”后可输入 AUTO/0 或手动 LO。
