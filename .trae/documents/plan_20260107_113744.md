# AFD01_QS设备状态显示修复方案

## 问题分析
经过分析代码，我发现了导致AFD01_QS设备状态显示为"N/A"的根本原因：

在`afd01_qs_protocol.py`文件的`parse_response`方法中，完整帧长度计算错误：
- 正确的完整帧长度应该是：帧头(1) + 命令(1) + 长度(2) + 数据(N) + CRC(2) = 6 + N
- 但代码中计算为：`total_frame_length = 5 + data_length`，这导致无法正确提取完整帧

由于帧长度计算错误，设备无法正确解析天线状态上报帧，导致设备信息无法更新，UI显示为"N/A"

## 修复方案
修改`afd01_qs_protocol.py`文件中的`parse_response`方法，将完整帧长度计算从`5 + data_length`改为`6 + data_length`：

```python
# 计算并检查完整帧长度
# 错误：total_frame_length = 5 + data_length  # 帧头(1)+命令(1)+长度(2)+数据(N)+CRC(2)
# 正确：
total_frame_length = 6 + data_length  # 帧头(1)+命令(1)+长度(2)+数据(N)+CRC(2)
```

## 修复后预期效果
1. 设备能够正确解析天线状态上报帧
2. 设备信息能够被正确更新
3. UI显示的设备状态不再是"N/A"，而是实际的设备状态数据
