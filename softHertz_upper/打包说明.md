# softHertz调试工具打包说明

## 1. 打包脚本介绍

`build_exe.py` 是用于将softHertz调试工具打包成.exe可执行文件的脚本。

## 2. 打包前准备

### 2.1 安装依赖

脚本会自动检查并安装必要的依赖，但建议先手动安装：

```powershell
python -m pip install PyInstaller>=6.0.0 PyQt5>=5.15.0 pyqtgraph>=0.13.0 pyserial>=3.5
```

### 2.2 创建虚拟环境（推荐）

为了避免中文路径问题，推荐在英文路径下创建虚拟环境：

```powershell
# 创建虚拟环境
python -m venv d:\pyqt5_env

# 激活虚拟环境
D:\pyqt5_env\Scripts\activate.ps1

# 安装依赖
python -m pip install PyInstaller>=6.0.0 PyQt5>=5.15.0 pyqtgraph>=0.13.0 pyserial>=3.5
```

## 3. 打包步骤

### 3.1 基本打包

在项目根目录下执行以下命令：

```powershell
# 在虚拟环境中执行
python build_exe.py
```

### 3.2 可选参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--debug` | 启用调试模式 | 关闭 |
| `--console` | 显示控制台窗口 | 关闭 |
| `--onedir` | 生成目录模式的可执行文件 | 开启（推荐） |
| `--name` | 应用程序名称 | `softHertzDebugTool` |
| `--icon` | 图标文件路径 | `code/soft_hertz_logo_deepspace_blue_512.ico` |
| `--distpath` | 输出目录 | `dist` |
| `--workpath` | 工作目录 | `build` |
| `--no-install` | 不自动安装依赖 | 关闭 |

### 3.3 示例

```powershell
# 生成带控制台的可执行文件
python build_exe.py --console

# 自定义应用程序名称
python build_exe.py --name MyDebugTool
```

## 4. 打包结果

打包成功后，可执行文件将生成在以下位置：
- 目录模式：`dist/softHertzDebugTool/softHertzDebugTool.exe`
- 单文件模式（不推荐）：`dist/softHertzDebugTool.exe`

## 5. 运行可执行文件

### 5.1 目录模式

直接双击 `dist/softHertzDebugTool/softHertzDebugTool.exe` 即可运行。

### 5.2 单文件模式

直接双击 `dist/softHertzDebugTool.exe` 即可运行。

## 6. 常见问题

### 6.1 中文路径问题

如果遇到中文路径导致的打包失败，推荐使用虚拟环境，或确保项目路径中不包含中文字符。

### 6.2 依赖安装失败

手动安装依赖：

```powershell
python -m pip install PyInstaller>=6.0.0 PyQt5>=5.15.0 pyqtgraph>=0.13.0 pyserial>=3.5
```

### 6.3 图标文件不存在

确保 `code/soft_hertz_logo_deepspace_blue_512.ico` 文件存在，或使用 `--icon` 参数指定其他图标文件。

## 7. 注意事项

1. 推荐使用目录模式（`--onedir`），避免单文件模式可能遇到的路径问题。
2. 打包后的可执行文件包含所有必要的依赖和资源。
3. 如果修改了代码，需要重新执行打包命令。
4. 虚拟环境中的依赖安装只需要执行一次。
