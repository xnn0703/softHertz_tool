# AFDTR/QS 双型号上位机实施计划

## 目标

- 以当前 PySide6 AFDTR 工具为基线，增加手动型号切换和独立 QS V1.6 后端，不直接合并旧 master。
- 增加可复制、筛选、自动保存的统一报文监视器。
- QS 页面增加 0x0B/0xA1 阵列配置、状态回读和 TX/RX 8x8 可视化，可选 8x8、7x7、6x6、5x5、4x4。

## 关键行为

- 首次默认 AFDTR，记忆最近型号；切换时断开隐藏页面串口。
- QS 默认 921600；A0 可按 100Hz 接收，业务 UI 最多 10Hz 刷新。
- QS 串口状态区实时显示 A0 上报频率，使用约 2 秒滑动窗口；超过 1 秒未收到 A0 时显示超时。
- 阵列请求同一时间只允许一个，3 秒超时且不自动重发。
- 自动日志保存到 Documents/SoftHertz/AFDTR_Tool/logs，50MiB 轮转，不自动删除。

## 边界

- AFDTR 现有协议与三设备功能保持不变。
- 旧 master 只参考功能语义，不复用 PyQt5 控制器和旧协议偏移。
- 保持现有 EXE 和发布产物名称。
