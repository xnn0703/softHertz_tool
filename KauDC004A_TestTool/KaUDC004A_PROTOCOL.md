## 2. 帧格式定义

### 2.1 帧结构 (10字节)

```
[Byte0][Byte1][Byte2][Byte3][Byte4][Byte5][Byte6][Byte7][Byte8][Byte9]
  帧头                      命令码  参数...
```

**注意**: 文档中帧头未明确定义，但 CRC 计算范围是字节0-9。

### 2.2 CRC 计算方式

| 参数 | 值 |
|------|-----|
| 多项式 | G(X) = X^16 + X^12 + X^5 + 1 |
| Poly 值 | 0x1021 |
| 初始值 | 0xFFFF |
| CRC 校验范围 | 字节0 ~ 字节9（帧头 + 载荷） |
| 传输方式 | 大端字节序 (Big Endian) |

**功能**: 复位整个变频分机。

### 3.3 温度查询

**命令码**: `0x0C`

| 字段 | Byte4 | Byte5 | Byte6 | Byte7 | Byte8 | Byte9 |
|------|-------|-------|-------|-------|-------|-------|
| 命令 | 0x0C | 0x00 | 0x00 | 0x00 | 0x00 | 0x00 |
| 回复 | 0x0C | Temp | 0x00 | 0x00 | 0x00 | 0x00 |

**温度编码规则**:
- `0x80 = 0℃`
- 小于 `0x80` → 负温度
- 大于 `0x80` → 正温度
- 分辨率：1 bit = 1℃

**计算公式**:
```python
if temp >= 0x80:
    temperature = temp - 0x80  # 正温度
else:
    temperature = -(0x80 - temp)  # 负温度
```

### 3.7 发射衰减

| 字段 | Byte4 | Byte5 | Byte6 | Byte7 | Byte8 | Byte9 |

| 命令 | 0x14 | 0x00 | 0x00 | 0x00 | Tx_ATT | Tx_ATT |
| 回复 | 0x14 | 0x00 | 0x00 | 0x00 | Tx_ATT | Tx_ATT |


## 6. CRC 计算参考

```python
def crc16_ccitt(data: bytes, poly=0x1021, init_val=0xFFFF):
    crc = init_val
    for byte in data:
        crc ^= byte << 8
        for _ in range(8):
            if crc & 0x8000:
                crc = (crc << 1) ^ poly
            else:
                crc <<= 1
            crc &= 0xFFFF
    return crc
```
