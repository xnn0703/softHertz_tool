# softHertz串口调试工具

## 项目概述
这是一个基于Python的通用设备调试工具，采用模块化设计，将通用功能（如串口控制）与设备特定功能（如协议处理、UI界面）分离，使工具能够轻松适配不同的设备。

## 项目结构

├── app.py                 # 主程序入口，整合所有组件

## 架构设计

### 分层架构

1. **通用层 (common/)**
   - 提供与设备无关的基础功能
   - 包含串口控制、基础协议接口、基础设备接口
   - 可以被不同设备共享使用

2. **设备特定层 (devices/)**
   - 实现特定设备的协议和通信逻辑
   - 继承自通用层的基类
   - 处理设备特定的数据格式和命令

3. **UI层 (ui/)**
   - 提供用户界面，分为通用UI和设备特定UI
   - 负责与用户交互和显示设备状态

4. **应用层 (app.py)**
   - 整合所有组件，启动应用程序
   - 管理组件间的依赖关系

## 主要组件说明

### 1. 串口控制器 (SerialController)
- 提供串口设备的枚举、连接、断开功能
- 处理数据的发送和接收
- 实现接收线程和日志记录

### 2. 协议层
- **ProtocolBase**: 定义协议处理的抽象接口
- **KauDC004AProtocol**: 实现KauDC004A设备的特定协议，包括帧构建、解析和CRC校验

### 3. 设备层
- **DeviceBase**: 定义设备通信的抽象接口
- **KauDC004ADevice**: 实现与KauDC004A设备的通信逻辑，包括命令发送和数据解析

### 4. UI层
- **UIBase**: 提供通用的UI组件，如串口选择、日志显示等
- **KauDC004AUI**: 实现KauDC004A设备特定的UI，如状态表格、命令发送区域等

### 5. 应用入口 (Application)
- 初始化并整合所有组件
- 管理应用的生命周期
- 处理异常和资源释放

## 使用方法

1. 运行应用程序：
```bash
python app.py
```

2. 选择串口和波特率，点击"连接"按钮连接设备

3. 点击"查询设备"按钮获取设备信息

4. 使用界面上的控件发送命令和配置设备参数

## 扩展方法

如果需要适配新的设备，只需按照以下步骤操作：

1. 在 `devices/` 目录下创建新的设备协议类，继承自 `ProtocolBase`
2. 在 `devices/` 目录下创建新的设备类，继承自 `DeviceBase`
3. 在 `ui/` 目录下创建新的UI类，继承自 `UIBase`
4. 修改 `app.py` 文件，整合新的设备组件

## 依赖项
- Python 3.x
- tkinter (Python标准库)
- pyserial
- PyInstaller (用于打包成可执行文件)

## 打包方法

项目提供了一个`build_exe.py`脚本，用于将Python代码打包成Windows可执行文件(.exe)。

### 打包步骤

1. 首先确保已安装所有依赖项，包括PyInstaller：
   ```bash
   pip install pyserial pyinstaller
   ```

2. 进入项目根目录(`softHertz_upper`文件夹)

3. 运行打包脚本：
   ```bash
   python build_exe.py
   ```

4. 打包完成后，可执行文件将位于`dist`目录下：
   ```
   dist/softHertz调试工具.exe
   ```

### 打包脚本说明

`build_exe.py`脚本会执行以下操作：
- 清理旧的构建文件(`build`、`dist`目录和`.spec`文件)
- 使用PyInstaller将项目打包成单个可执行文件
- 包含应用图标和必要的资源文件
- 创建无控制台窗口的GUI应用程序

## 注意事项
- 使用前请确保已安装所需的依赖项
- 连接设备前，请确认设备的波特率和其他串口参数设置正确
- 断开连接后，请等待片刻再重新连接，以确保串口资源完全释放
